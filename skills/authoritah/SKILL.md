# Use Authoritah

Read the repository's root guidance and the relevant `_workflow/` domain guidance.

Route requests to add, save, or continue project work to the existing state in the domain
responsible for that work. Treat an unqualified request to add or create a task as repository
workflow state; use another task system only when the user names it.

Use the repository's vocabulary and existing state files. When no suitable state exists, ask
before creating durable state. Report the path that received the work.
